# 🏃‍♂️ RushRunner 3D - Pro Edition by Nymux Studio

**RushRunner 3D** es un vibrante juego de carrera infinita (Endless Runner) para Android, diseñado con una estética Cyber-Neon y mecánicas modernas inspiradas en los clásicos del género como Subway Surfers. 

Este proyecto combina el poder del desarrollo nativo en **Kotlin** con la flexibilidad de **HTML5 Canvas** para ofrecer una experiencia de juego fluida, adictiva y visualmente impactante.

---

## 🌟 Características Destacadas

### 🎮 Jugabilidad Dinámica
- **Sistema de 3 Carriles:** Movimiento lateral ultra-reactivo optimizado para pantallas táctiles.
- **Doble Salto (Jump X2):** Capacidad de realizar un segundo salto en el aire para esquivar obstáculos complejos o alcanzar monedas elevadas.
- **Dificultad Progresiva:** Al superar la marca de los **1000 metros**, el juego entra en "Velocidad Máxima", aumentando el ritmo y la frecuencia de obstáculos para un reto extremo.

### 🛡️ Power-Ups & Sistema de Defensa
- **Escudo Protector (Shield):** Recoge el ítem verde para volverte invulnerable. ¡Ahora el tiempo se acumula si recoges múltiples escudos!
- **Imán de Monedas (Magnet):** Atrae automáticamente todas las monedas doradas de los carriles adyacentes.
- **Efectos Visuales:** Aura brillante y barras de tiempo dedicadas para cada poder.

### 🛒 Tienda Pro (Economía del Juego)
- **Monedas Acumulables:** Recolecta monedas en cada carrera para mejorar tu inventario.
- **Compra de Vidas (❤️):** Asegura tu récord comprando vidas para revivir después de un choque.
- **Equipamiento de Inicio:** Compra Escudos o Imanes en la tienda para empezar tu próxima carrera con ventaja táctica.

### 📱 Experiencia Android Profesional
- **Modo Vertical (Portrait):** Optimizado para jugar cómodamente con una sola mano.
- **Pantalla Completa Inmersiva:** Integración nativa que oculta barras de sistema para aprovechar cada píxel.
- **Identidad Nymux Studio:** Logo personalizado integrado en menús, pantallas de carga e icono de la aplicación (APK).
- **100% en Español:** Interfaz amigable y clara para el usuario.

---

## 🛠️ Stack Tecnológico

- **Android Nativo:** Implementado en **Kotlin** con un WebView de alto rendimiento.
- **Game Engine:** Motor pseudo-3D propio desarrollado en **Vanilla JavaScript**.
- **Gráficos:** Renderizado mediante **HTML5 Canvas API** (sin assets externos pesados).
- **Estilos:** **CSS3 Moderno** con efectos de Glassmorphism y Neón.
- **Persistencia:** Almacenamiento local para monedas, récords y compras.

## 🚀 Instalación y Desarrollo

### Requisitos
- Android Studio Ladybug (o superior).
- Dispositivo Android con API 24 (Nougat) o superior.

### Pasos para Ejecutar
1. Clona este repositorio: `git clone https://github.com/TU_USUARIO/RushRunner.git`
2. Abre el proyecto en **Android Studio**.
3. Sincroniza el proyecto con los archivos de Gradle.
4. Conecta tu dispositivo vía USB o inicia un Emulador.
5. Haz clic en el botón **"Run"** (Play) de Android Studio.
